# Traffic Light Simulator

A small frontend project that demonstrates a basic traffic-light interface using HTML, CSS, and JavaScript.

The page displays red, yellow, and green traffic-light indicators, a status message, and a button that updates the message.

## Features

- Visual traffic-light interface with three colored indicators.
- Status message displayed on the page.
- Button interaction handled with JavaScript.
- Simple structure that can be used to practice DOM selection, event listeners, and CSS classes.

## Getting Started

No installation or build tools are required.

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or run it with the Live Server extension.

## Built With

- HTML
- CSS
- JavaScript

## Project Files

- `index.html` — Page structure and traffic-light elements.
- `style.css` — Visual styles for the interface.
- `app.js` — Button interaction and traffic-light state changes.

## How It Works

The JavaScript selects the traffic-light elements and the status message. The page initializes the light state and attaches a click event to the **Change Light** button. In this current version, the button updates the status text; it does not implement a timed, repeating traffic-light cycle.

## Project Status

This is a basic educational exercise and can be extended with automatic light timing, a complete red-yellow-green sequence, and pedestrian-crossing controls.
